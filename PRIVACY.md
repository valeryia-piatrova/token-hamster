# Privacy

Token Hamster collects nothing and sends nothing.

- **What it reads:** the token counts, plan limits, reset times and cost that Claude Code reports for your own session, the name of each tool Claude calls, to count calls per tool, and the list of subagents in the session, to name their types. It does not read your prompts, Claude's replies, your files or what is passed to a tool.
- **What it keeps:** one number, your lifetime token total, in Claude Code's local plugin store on your machine. Everything else lives in memory and is gone when the session ends.
- **What it sends:** nothing. Token Hamster makes no network requests, runs no processes and has no analytics or telemetry.

Questions: open an [issue](https://github.com/valeryia-piatrova/token-hamster/issues).
