Token Hamster Claude Code mod for token usage & limits

Token Hamster is a Claude Code mod that shows your token usage, your 5-hour and weekly plan limits, when they reset, and what each turn costs, live, inside Claude Code. An animated hamster eats every token Claude eats, so you see your usage at a glance instead of running a separate command.

What it shows

Token usage

Input, output, cache read and cache write tokens for the session, plus a lifetime total.

5-hour and weekly limits

Both plan limits as percent left, with a refill in … countdown to the reset.

Run-out forecast

Your pace per turn and when the session limit will run out at that pace.

Cost per turn

Cost per turn and for the session, and the cache hit rate.

Who spends the tokens

Usage by the main loop and each subagent type, by tool and by model.

Statusline

🐹 all 3.9M · session 62% · week 95% · credits $1.99 under the prompt.

No API key, no log scraping, nothing estimated: the numbers come from Claude Code's own usage data at the end of every turn.

The mood follows your rate limits

The hamster's mood follows the emptiest limit, the 5-hour session or the week. At half the limit it frowns and sweats. With a quarter left it runs it off in its wheel. When the limit is used up it sleeps in its house and counts down to the reset.

A usage dashboard inside Claude Code

/hamster (or Details) opens a pane with the counts and where the tokens went: what fills the context window, tokens per turn with a forecast, the main loop against each subagent type, tool calls, models, cache hit rate and cost per turn.

On desktop, VS Code and mobile it's an animated SVG; in the terminal it's a colour pixel-art hamster drawn in half blocks, with the same moods.

Claude Code tokens and limits, explained

What are tokens in Claude Code?

Tokens are the pieces of text the model reads and writes, and every Claude Code turn spends four kinds: input (your prompt and the context sent with it), output (what Claude writes), cache read (context reused from the prompt cache) and cache write (context saved to the cache for later turns). Token Hamster counts all four for the session and keeps a lifetime total, and the seeds the hamster eats are coloured by that real mix.

How do I check my Claude Code token usage?

Claude Code's built-in commands show a snapshot when you ask for it. Token Hamster keeps your token usage on screen the whole time: in the terminal, in VS Code, in the desktop app's Code tab and on mobile. The cage above the prompt shows tokens eaten and limits left, the statusline shows the totals, and /hamster opens a full token usage dashboard.

What is the Claude 5-hour limit?

On Claude plans with usage limits, such as Pro and Max, Claude Code usage counts against a 5-hour session limit and a weekly limit. Claude Code reports each limit as a percentage used, not as a number of tokens, so Token Hamster shows how much of each limit is left, for example session 62% · week 95%, and the hamster's mood follows whichever is emptier.

How many tokens do I get on Claude Pro or Max?

Limits depend on your plan and are set by Anthropic; Claude Code shows them as a share of the limit rather than a fixed token count. The practical question is how fast you are using it, so Token Hamster tracks tokens per turn and turns your pace into a forecast: at this pace the session limit runs out in ~1h 20m.

When does my Claude usage limit reset?

Each limit resets at the end of its window: the 5-hour session limit and the weekly limit have their own reset times. Token Hamster reads the reset time Claude Code reports and counts down to it with refill in …. When a limit reaches 0%, the hamster sleeps in its house until the limit resets.

What happens when I hit the Claude Code usage limit?

When a limit is used up you have to wait for it to reset. Token Hamster warns you on the way there: the hamster gets worried at half the limit and runs in its wheel with a quarter left, so the limit never surprises you mid-task.

How much does a Claude Code turn cost?

Token Hamster turns tokens into dollars using the cost Claude Code reports for the session, and shows the cost per turn, the session total and the credits used in the statusline. Nothing is estimated from price tables.

What is the cache hit rate?

Claude Code reuses context through prompt caching: cache read tokens cost less than fresh input. The cache hit rate is the share of input served from the cache. Token Hamster shows it per turn, so you can see when the cache stops working, for example after a long pause.

Is my Claude Code context window full?

The pane shows how much of the context window is left and what fills it, by category, as /context lists it: system prompt, tools, skills, MCP tools and messages.

How do I reduce Claude Code token usage?

Start by seeing where the tokens go. The Token Hamster pane breaks usage down by the main loop and each subagent type, by tool and by model, shows what fills the context, and tracks cost and cache hit rate per turn. That makes it easy to spot a subagent, tool or MCP server that burns tokens, and to compact or start a fresh session before the context gets heavy.

Install

It installs like any Claude Code plugin. In Claude Code, run:

/plugin marketplace add valeryia-piatrova/token-hamster
/plugin install token-hamster@token-hamster

The cage band sits above the prompt. Press Details (d) or type /hamster to open the pane. Requires Claude Code 2.1.289 or later; the limit bars and moods appear on plans with usage limits (Pro and Max). More options are in the README.

Private by design

Token Hamster reads only the session's own usage data, tool names and subagent types. It keeps one number, your lifetime token total, on your machine, and makes no network requests. See the privacy policy.
